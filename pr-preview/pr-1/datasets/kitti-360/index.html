KITTI-360

The 360° successor of KITTI – nine long Karlsruhe sequences with stereo and fisheye cameras, a 64-beam LiDAR, 3D primitives and dense 2D and 3D semantic labels.

byAutonomous Vision Group (University of Tübingen & MPI for Intelligent Systems)· released 2020

Free, but you must create an account and/or accept terms before downloading (login walls, gated Hugging Face repositories with automatic approval). Last verified 14 Oct 2026 by an agent. Non-commercial use under CC BY-NC-SA 3.0; downloads require a cvlibs account.

Overview

KITTI-360 revisits the KITTI recording setup with full 360° coverage: a perspective stereo pair, two fisheye side cameras and a 64-beam LiDAR on the same Karlsruhe streets, driven in a single day in 2013. Instead of per-frame boxes it provides 3D primitives annotated once in the global frame and dense semantic and instance labels in 2D and 3D, which makes it a reference for scene understanding, scene completion and novel view synthesis. Its 9 sequences are long, which is unusual among driving datasets built from 20-second snippets.

History and availability

The data has been served from the cvlibs servers since its release and needs only a free account. The licence is non-commercial and share-alike. In September 2026 the servers had to be restored from a backup, which is a reminder that even stable academic hosting depends on one group's infrastructure.

Access

Register on the cvlibs website and download the raw 2D and 3D data, poses, calibration and 3D boxes. py123d expects the official directory layout and converts all sequences with a single command; semantic labels are not converted yet.

Quirks and errata

  • Boxes are annotated globally; per-frame visibility is derived from the number of LiDAR points inside a box.
  • The ground primitives describe surfaces, not lanes.
  • Ego-vehicle parameters are partially estimated.

Dataset docs

Read this dataset through py123d's unified Arrow format and API. Converted logs reference the original image and LiDAR files by relative path.

pip install py123d
py123d-conversion dataset=kitti360
