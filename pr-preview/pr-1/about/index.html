About

A community-maintained wiki of autonomous driving datasets, with availability as a first-class, dated, evidence-backed field.

Why

Autonomous-driving datasets are cited for years after their download links die. Lyft Level 5 is gone, PandaSet's official page vanished, Argo AI shut down while its data lived on, and gated releases quietly change their terms. Survey papers and awesome-lists capture a snapshot and then rot; none of them record whether you can still get the data, when that was last checked, or where a mirror lives.

Embodied Datasets treats availability as a first-class, dated, evidence-backed field. Each dataset is one YAML record in a public repository, validated by a strict schema in CI and rendered into this site. Edits go through pull requests; agents may draft records and run link checks, but a status change to "discontinued" and every licence interpretation is confirmed by a human.

What a record contains

  • Identity and provenance: name, aliases, family, version, release date, organizations, papers (with BibTeX), code and docs links.
  • Availability: status, verification date and verifier, access method, cost and eligibility, evidence URLs with Wayback snapshots, mirrors, download size and a dated history of changes.
  • Legal: licences per component (data, annotations, maps, code), terms of use, a plain-language permission summary and privacy notes.
  • Collection and scale: real or synthetic, platform, cities with coordinates, hours, kilometres, logs and frames.
  • Sensors, annotations, maps, splits, benchmarks, formats and tooling: one entry per sensor with py123d IDs (which draw the rig diagrams), annotation types from a controlled vocabulary, map type and layers, split sizes, evaluation-server status, raw formats, devkit health and loaders.
  • Curation: who wrote and updated the record, a confidence level and a sources map from field to URL.

The schema is published as JSON Schema; the whole database is exported as JSON and CSV on every build.

Availability statuses

StatusMeaning
AvailablePublicly downloadable without an account (direct link, open cloud bucket, torrent, open Hugging Face repository).
Registration requiredFree, but you must create an account and/or accept terms before downloading (login walls, gated Hugging Face repositories with automatic approval).
Application requiredAccess is granted manually after an application, e.g. academic-only programmes or signed agreements.
Partially availableSome subsets, modalities or releases have been withdrawn while others remain downloadable.
Official source gone, mirrors existThe official download has disappeared or is no longer maintained, but the data can still be obtained from re-hosts or mirrors listed in the record.
DiscontinuedNo longer obtainable from any known source.
SupersededWithdrawn in favour of a successor dataset; see the successor pointer.
UnverifiedStatus has not been checked by a human or an agent yet. Treat every other field with caution.

Rules of evidence: a status needs at least one dated observation of a concrete URL (the download page, a hosting API such as Hugging Face's, or an archived snapshot). Login walls and rate limits cause false positives, so an automated check never flips a dataset to discontinued on its own.

Scope

The first release covers the datasets supported by py123d, the library that converts driving datasets into one Arrow format. That gives every record a working loader and measured scale figures. The schema already carries a domain field so that robotics datasets beyond driving can join later.

Prior art

EffortWhat it isGap
ad-datasets (Bogdoll et al.)JSON record per dataset, React site with filters, citation counts, 150+ datasetsUnmaintained since 2023; no availability status; single data.json invites merge conflicts
TUM survey (Liu et al. 2024)265 datasets by modality, size, tasks, conditionsTables as PDF; no structured data or site
OpenDriveLab data surveyMarkdown tables with sensors, scale, annotationsNewest entries 2023; markdown only
Awesome lists, AWS Open Data, Hugging Face tagsLink lists and hosting cataloguesUnstructured, or limited to what they host

Nobody tracked availability, verification dates or mirrors, and every structured effort died with its single maintainer. Hence: a low-friction PR workflow, agents for the boring parts, and a schema that is small enough to be filled.
