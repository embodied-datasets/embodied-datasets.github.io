Contribute

Everything on this site comes from YAML files in a public repository. Fixing a fact is a one-line pull request; adding a dataset is one directory.

Three ways to help

  1. Request a dataset. Open an "Add dataset" issue with the homepage and paper URL. A maintainer (or an agent, reviewed by a maintainer) drafts the record.
  2. Fix or verify a fact. Every dataset page has an "Edit on GitHub" button. If you confirm an availability status, set verified_by: human, bump last_verified and add what you observed to evidence.
  3. Add a record yourself. Follow the steps below.

Adding a record

  1. Fork and clone the repository, run npm install.
  2. Create datasets/<slug>/dataset.yaml. Slugs are lowercase with hyphens. Add organizations/<slug>.yaml and families/<slug>.yaml if they do not exist.
  3. Optionally add datasets/<slug>/page.md with an overview, history and access tips. Reference numbers with shortcodes such as {{ scale.hours }} instead of typing them; the build fails on a shortcode that does not resolve.
  4. Run npm run validate (schema and cross-references), npm run lint:prose (bare numbers in prose) and npm run build.
  5. Open a pull request. CI runs the same checks; invalid records cannot be merged.

Minimal record

name: Example Dataset
tagline: One sentence that says what makes this dataset different.
domain: driving
family: example-family            # optional, slug of families/<slug>.yaml
release_date: 2024-05             # YYYY, YYYY-MM or YYYY-MM-DD
organizations: [example-org]      # slugs of organizations/<slug>.yaml
homepage: https://example.org/dataset
papers:
  - title: "Example: A dataset"
    venue: CVPR 2024
    year: 2024
    arxiv: "2405.12345"
availability:
  status: available-registration
  last_verified: 2026-10-14
  verified_by: human
  access_methods: [registration]
  cost: free
  evidence:
    - url: https://example.org/download
      checked: 2026-10-14
      http_status: 200
      note: Download page online; requires a free account.
legal:
  licenses:
    - { id: CC-BY-NC-SA-4.0, name: Creative Commons BY-NC-SA 4.0, url: https://creativecommons.org/licenses/by-nc-sa/4.0/ }
  permissions: { commercial: false, attribution_required: true }
collection:
  reality: real
  locations:
    - { city: Karlsruhe, country: DE, lat: 49.01, lon: 8.40 }
scale: { logs: 1000, log_unit: scenes, scene_duration_s: 20, hours: 5.6 }
modalities: [ego_pose, camera, lidar, boxes_3d]
sensors:
  - { type: camera, count: 6, hz: 12, resolution: 1600×900, ids: [PCAM_F0, PCAM_B0] }
  - { type: lidar, count: 1, hz: 20, beams: 32, ids: [LIDAR_TOP] }
annotations:
  - { type: boxes_3d, classes: 23, hz: 2, method: human }
maps: { available: false }
sources:
  scale: https://example.org/dataset
curation:
  created: 2026-10-14
  updated: 2026-10-14
  contributors: ["Your Name"]
  schema_version: 0.1.0

Unknown keys are rejected, so typos surface immediately. Enumerations live in vocabularies/*.yaml; the full field list is in schema/dataset.schema.json.

What counts as evidence

  • A dated check of the official download page or hosting API (status code and what you saw), ideally with a Wayback Machine snapshot URL.
  • For gated Hugging Face datasets: the API response (gated, private, lastModified).
  • For a disappearance: the first archived snapshot showing the failure, an issue thread, or an announcement.
  • Mirrors need a host, URL, whether they are official, and when you last checked them.

An agent may set any status except discontinued; that one, and every licence interpretation, needs a human.

Conventions

  • Numbers and URLs live in dataset.yaml. Prose refers to them through shortcodes.
  • Scale figures measured from the released data (for instance by py123d) are preferred over marketing numbers; say which in sources.
  • Years alone are fine where the month is unknown (release_date: 2020).
  • Keep curation.notes for things a reviewer should double-check.

Embodied Datasets

A community-maintained wiki of autonomous driving datasets, with availability as a first-class, dated, evidence-backed field.

Records are CC BY 4.0, code is MIT. Facts are only as good as their sources: every record links its evidence and names who verified it last.
